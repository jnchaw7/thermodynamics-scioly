DRAFT AREA VII (C only)

Enthalpy

H=U+PV, constant-pressure heat, state functions, and sign interpretation.

Why it matters: Enthalpy is explicitly Division C only in the draft, and chemistry-flavored thermodynamics tests often use it heavily.
Practice this rule areaJump to mini quiz

Definition

  • Enthalpy is H=U+PV. Like U and S, H is a state function.
  • It is not “heat contained in a system”; heat is energy transfer, while enthalpy is a property of state.

Why constant pressure matters

  • For a process at constant pressure with only PV work, qp=ΔH.
  • This is why many reactions and phase changes performed at atmospheric pressure are conveniently described by enthalpy changes.

Sign

  • ΔH<0 means the system releases heat to surroundings under constant-pressure PV-work conditions (exothermic).
  • ΔH>0 means the system absorbs heat under those conditions (endothermic).

Formula / memory box

H = U + PVqp = ΔH (constant P, PV work only)

Worked example

Prompt

At constant pressure, ΔH=−35 kJ for a process with only PV work.

Solution

qp=−35 kJ: the system releases 35 kJ.

MINI QUIZ

Practice before you leave

Try each one without opening the answer. Then reveal it to self-check.

Write the definition of H.
Answer: H=U+PV.
Is enthalpy a state function?
Answer: Yes.
Under what common conditions does qp=ΔH?
Answer: Constant pressure with only PV work.
If ΔH=+50 kJ under those conditions, does the system absorb or release heat?
Answer: Absorb 50 kJ.
If ΔH=−80 kJ, is the process exothermic or endothermic?
Answer: Exothermic.
Is enthalpy the same thing as heat?
Answer: No. Enthalpy is a state property; heat is energy transferred across a boundary.
