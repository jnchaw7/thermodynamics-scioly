DRAFT AREA VII (C only)

Entropy

State-function entropy, ΔS=Qrev/T, spontaneous direction, and phase-change entropy.

Why it matters: Entropy is explicitly Division C only in the draft and is a favorite source of conceptual plus numerical questions.
Practice this rule areaJump to mini quiz

Entropy as a state function

  • Entropy S depends only on the equilibrium state, not the path taken to reach it.
  • Heat Q is path-dependent, but ΔS can be calculated along any convenient reversible path connecting the same endpoints.

Reversible heat transfer

  • For reversible isothermal transfer, ΔS=Qrev/T.
  • For a reversible phase change at its equilibrium temperature, ΔS=mL/T.

Second-law direction

  • For an isolated system, total entropy cannot decrease. A spontaneous irreversible change increases total entropy.
  • System entropy itself may decrease if surroundings gain more entropy; the second law applies to the total isolated combination.

Formula / memory box

ΔS = Qrev/T (reversible isothermal)ΔSphase = mL/TΔStotal ≥ 0 for an isolated spontaneous process

Worked example

Prompt

600 J is absorbed reversibly at 300 K.

Solution

ΔS=600/300=2.00 J/K.

MINI QUIZ

Practice before you leave

Try each one without opening the answer. Then reveal it to self-check.

Is entropy a state function or path function?
Answer: State function.
A system reversibly absorbs 900 J at 300 K. Find ΔS.
Answer: 3 J/K.
If a system releases heat reversibly at fixed T, is its ΔS positive or negative?
Answer: Negative.
What is ΔS for a reversible phase change using latent heat?
Answer: mL/T.
Can system entropy decrease in a spontaneous process?
Answer: Yes, if surroundings gain enough that total entropy still increases.
What must happen to total entropy of an isolated system in a spontaneous irreversible process?
Answer: It increases.
